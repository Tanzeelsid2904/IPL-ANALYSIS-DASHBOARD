# 🏏 IPL Analysis Dashboard | Power BI

## 📌 Project Overview

An interactive IPL Analysis Dashboard developed using Microsoft Power BI to analyze IPL match data, team performance, player statistics, and overall tournament trends from 2008 to 2025.

The dashboard transforms raw IPL data into meaningful and interactive visual insights using data cleaning, transformation, DAX, and data visualization techniques.

## 📊 Key Analysis

- 🏆 Total IPL Matches and Seasons
- 🏏 Team-wise Performance Analysis
- 👤 Player Performance Analysis
- 🔥 Top Run Scorers
- 🎯 Top Wicket Takers
- 6️⃣ Most Sixes
- 4️⃣ Most Fours
- 🏅 Team-wise and Player-wise Statistics
- 📈 Season-wise Performance Trends
- 🏟️ Venue-wise Match Analysis
- 🪙 Toss Decision & Match Outcome Analysis
- 🏆 IPL Winner Analysis

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization
- Dashboard Design

## 🎯 Project Objective

The objective of this project is to analyze historical IPL data and create an interactive dashboard that makes it easy to identify team and player performance trends and gain meaningful insights from the data.
